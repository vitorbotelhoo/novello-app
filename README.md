# novello

A free, open-source, fully-local mind-mapping app for macOS. Infinite canvas, shortcut-driven tools, no account, no cloud required.

Novello (Portuguese for "thread/skein") treats mind maps as what they are: connected threads. The visual language leans into that, pastel tones, wiggly thread-like connectors, instead of plain connector lines.

Status: early scaffold, no product features yet.

## Stack

- [Tauri 2](https://tauri.app/) (Rust) for the native macOS app shell
- React 19 + TypeScript, built with Vite

## Development

```bash
npm install
npm run tauri dev
```

See `CLAUDE.md` for full commands and architecture notes.
